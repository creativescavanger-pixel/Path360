# PATH360 App Documentation

This document explains the app in plain, understandable language.

## What this app is
PATH360 is a founder-support web app. It helps a founder work through assessments, guided document prep, and business planning tasks. The app is built as a React web app and is deployed through Vercel.

## Main purpose of the app
The app helps users:
- understand their founder stage
- complete diagnostic assessments
- prepare documents such as pitch decks, business plans, investor memos, and interviews
- save progress and continue later
- generate content with AI assistance

## How the app is organized
The project is organized into a few main areas:

- src/pages: the main screens or pages users see
- src/components: reusable UI pieces used inside pages
- src/lib: the logic behind the app, including AI, storage, guidance, and document generation
- src/stores: app state and shared data
- src/data: content and starter data
- public: static files such as icons and service worker

## How the guided document experience works
The guided document workflow is one of the main features of the app.

1. The user selects a document type such as a pitch deck or business plan.
2. The app loads a guide from src/lib/documentGuides.js.
3. The user answers questions in sections.
4. The app saves progress automatically.
5. When the user completes the flow, the app generates a draft document.
6. The document can be exported or used in the studio workspace.

## How the app stores data
The app uses a mix of:
- local app state with Zustand stores
- Supabase for database or auth-related storage
- AI-generated content that is tied to guided drafts and studio documents
